## Idee 1: Energiesparende Maschinenregelung ⭐ (Favorit)

### Szenario
Eine Maschine produziert Teile.

Der RL-Agent soll:

- Durchsatz maximieren
- Energieverbrauch minimieren
- Verschleiß minimieren

### Zustände

- aktuelle Temperatur
- aktuelle Drehzahl
- Werkzeugverschleiß
- Auftragslast

### Aktionen

- Drehzahl erhöhen
- Drehzahl senken
- Kühlung erhöhen
- Kühlung senken

### Belohnung

```text
+ Stückzahl
- Energieverbrauch
- Verschleiß
- Überhitzung
```

### Qt-Darstellung

Links:

- Animation einer Maschine

Rechts:

- Temperaturanzeige
- Energieverbrauch
- Produktionsrate
- Reward-Verlauf

Unten:

- Heatmap der Q-Tabelle

Man sieht sehr schön, wie der Agent anfangs überhitzt und später einen guten Arbeitspunkt findet.

# Empfehlung für eine Demo

Wenn das Ziel ist, Kollegen oder Management in wenigen Minuten RL verständlich zu machen, sind diese beiden Varianten besonders geeignet:

## Option A: AGV auf dem Werksgelände

Vorteile:

- hoher Industriebezug
- leicht verständlich
- gut visualisierbar
- sichtbarer Lernfortschritt

Beispiel:

```text
+-------------------+
| Lager             |
|        [AGV]      |
|                   |
| Maschine A        |
| Maschine B        |
| Versand           |
+-------------------+
```

Der Agent lernt, Material möglichst effizient zu transportieren.

---

## Option B: Temperaturregelung einer Maschine

Vorteile:

- sehr wenig Implementierungsaufwand
- direkter Bezug zur Regelungstechnik
- Vergleich mit PID-Reglern möglich
- besonders interessant für Ingenieure

Der Agent lernt selbstständig einen optimalen Betriebspunkt zu finden und Energieverbrauch gegen Regelgüte abzuwägen.
